# Watodo

**Watodo** is a task and habit tracker app for Android and iOS made with **Expo** and **Firebase**. It comes with a funny and playful UI. *(The app is currently only in French)*

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```
